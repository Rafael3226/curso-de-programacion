# Curso de Programacion

Curso completo de programacion desde cero. Cubre los fundamentos de computacion necesarios antes de escribir tu primera linea de codigo, y luego avanza hacia conceptos de programacion.

## Como usar este curso

Cada tema incluye:
- Explicacion teorica con diagramas
- Tablas de referencia
- Ejemplos practicos en Python y JavaScript (donde aplica)
- Ejercicios con respuestas

Se recomienda seguir el orden numerico, ya que cada tema construye sobre los anteriores.

## Requisitos

Ninguno. Este curso esta disenado para empezar desde cero.
